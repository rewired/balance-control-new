Objective and setup

Get as many of your real Influence markers onto the board as you can. The marker limit in the table is both the most you can own across the board and your supply, and the number you need on the board for an immediate win.

Set up a CORE match

  1. Choose Hotseat for play on one device or Network for the online lobby. In Hotseat, choose Human for each seat that a person will play.
  2. Choose 2–6 players. Clear all three boxes under Expansions for a CORE match. The game includes the extra tiles for 5–6 players automatically.
  3. Start the match. The game puts the Start Committee on the board, shuffles the other tiles into the draw pile and picks the starting player. Everyone begins with an empty Resource supply and the starting markers shown below.

What the tiles do

  • Resorts produce one type of Resource: DOM (Domestic Affairs), FOR (Foreign Affairs) or INF (Information and Media Control). A tile’s W number is its printed production value.
  • Committees let you spend Resources to create Influence. The Start Committee has its own price and can never hold a marker or be controlled.
  • Grassroots let you exchange Resources.
  • Lobbyists can give their controller extra Influence for deciding who leads on neighboring tiles.
  • Hotspots can put a marker onto the board when the last empty space around them is filled.

Optional variants

  • First-player handicap gives the starting player one fewer starting marker.
  • Tile recycling returns a tile to the draw pile if there is no empty hex next to a tile already on the board. The game reshuffles the pile and tries again. Each tile gets at most one attempt per turn. If only tiles with no possible placement remain after those attempts, the game goes to its final round settlement.
