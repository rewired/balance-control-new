Blockades and resolution order

Find where the effect resolves

When an effect uses a tile’s local rules, that tile is its Context Tile. A trade uses its Grassroots tile. Moving your Influence uses the destination. If a Measure directly places or moves a Regulation, use its destination. For direct removal, use the tile carrying the Regulation.

Example. You cannot move a marker onto a Blockaded tile. You can move your own marker away from it to an eligible tile because the destination is where that move resolves. An explicit restriction on moving the object still applies.

If the Authority Apparatus or Inner Order places or moves a Regulation, apply local rules at the Apparatus or Inner Order itself. You still check whether the destination accepts that Regulation type and whether a rule such as Surveillance prevents movement.

Resolve in this order

  1. Check Blockade. If it prevents the effect, stop before paying.
  2. Add costs. Each applicable Control or Administration adds 1 Resource to a player-paid effect, including an action with a base cost of zero. Add any other surcharges and check that the full cost can be paid. Automatic Resort production and normal Hotspot payouts skip these cost increases.
  3. Apply output changes. Each applicable Security Level subtracts 1 from an eligible gain. For production, combine these reductions with the other output changes before applying the minimum of zero. Ordinary placement or movement of an Influence marker does not count as a gain for Security Level.

Example. You control a Grassroots with Administration and Security Level. Trading 3 DOM for INF costs 3 DOM plus 1 Resource and yields zero INF. If you choose that legal action, you pay the full amount and use the action. If a Blockade also applies, the action is unavailable and you pay nothing.

If a Hotspot’s payout is blocked or reduced to zero on its first enclosure, that still uses up its one chance to pay out.
