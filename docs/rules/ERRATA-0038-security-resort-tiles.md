# ERRATA-0038 — Security ResortTiles

Date: 2026-11-10

Applies to EXP-02-00-08, EXP-02-01-07, EXP-02-03-07 and EXP-02-09-01.

With Security & Order active, add two SEC ResortTiles with printed value 1 and one with printed value 2 to the DrawPile. With the 5–6 Player Add-On, add one more SEC ResortTile with printed value 2. They follow the normal Resort production rules.

A standard Grassroots exchange into SEC yields 1 SEC before modifiers, like any other resort under CORE-01-04-22A. This supersedes the 2-SEC payout from ERRATA-0037.

New matches with EXP-02 record the Security ResortTiles rule at setup. Older matches keep their recorded tile pool and exchange payout, including matches created under ERRATA-0037.
