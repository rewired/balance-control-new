# ERRATA-0031 — Hexagonal topology

Date: 2026-11-09
Status: Accepted by the user
Applies to: CORE-01-00-T04

The current edition uses hexagonal adjacency for all matches. The topology interface remains the common source of adjacency for placement, Hotspot enclosure, and Lobbyist influence. TileRecycling and FirstPlayerHandicap remain optional under VAR-01.

New match setup rejects any other topology. Saved matches using the retired orthogonal topology cannot resume in this edition. Their saved data remains available for use with the original engine version.
