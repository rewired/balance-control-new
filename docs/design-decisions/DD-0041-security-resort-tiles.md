# DD-0041 — SEC als produzierendes Ressort

SEC soll über die Kontrolle von Resorts ins Spiel kommen. Beim früheren Test mit einer einzelnen W1-Kachel kontrollierte kein Spieler das SEC-Resort bei der Abrechnung. ERRATA-0038 verteilt deshalb drei SEC-Resorts mit den Werten 1, 1 und 2 auf den normalen Stapel. Für fünf oder sechs Spieler kommt ein zweites W2 hinzu. W1 finanziert bei alleiniger Kontrolle pro Abrechnung bereits eine normale Regulation. W2 macht das Feld als Produktionsziel attraktiver.

Die Kacheln werden zusammen mit dem übrigen Material gemischt. Der Standardtausch in SEC zahlt wie bei anderen Ressorts eine Einheit aus. Ein eigener Regelmarker erhält den Stapel und die Tauschauszahlung früherer Partien, einschließlich der 2-SEC-Auszahlung aus ERRATA-0037.
